Task Management API

REST API untuk mengelola project dan task tim, lengkap dengan autentikasi token, proteksi route, dan struktur resource yang rapi. Dites end-to-end lewat Postman, siap dikonsumsi frontend apa pun.

Yang dikerjakan

Autentikasi berbasis token

Laravel Sanctum menerbitkan personal access token saat login, dicabut otomatis saat logout.

Proteksi route middleware

Seluruh endpoint sensitif dibungkus auth:sanctum, menolak akses tanpa token yang valid.

Struktur resource konsisten

Projects memakai apiResource penuh; Tasks bersarang di bawah project untuk relasi yang jelas.

Kontrak respons yang rapi

Setiap respons mengikuti bentuk JSON yang konsisten, siap dikonsumsi frontend apa pun.
